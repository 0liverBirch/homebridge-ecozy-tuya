Device

Your clock's details live here, in the Homebridge config, and nowhere else. The device ID and local key never leave this page. Services for the device are edited in the raw config (this form preserves them untouched).

Saving writes the config; restart Homebridge for device changes to take effect.

Alarms

Set the four alarm times on the clock itself. This editor is served by the plugin through its existing connection to the clock, so nothing goes through the cloud. Open the alarm editor in a new tab if it does not load below.
