Find your clocks

Scan your network: Tuya devices announce their ID and IP address (the scan takes about 12 seconds). You will still need each clock's local key from the Tuya IoT platform - it is never broadcast, and each clock has its own. Use "Use this device" to drop a found clock into the form below, then type its key in.

Clocks

Each clock's details live here, in the Homebridge config, and nowhere else. You can run several clocks from this one plugin. The services each clock exposes in HomeKit are kept as they are (this form preserves them untouched); a clock added here gets the standard set.

Saving writes the config; restart Homebridge for clock changes to take effect.

Alarms

Set the alarm times on each clock itself. This editor is served by the plugin through its existing connections to the clocks, so nothing goes through the cloud. With more than one clock there is a clock switcher at the top of the editor. Open the alarm editor in a new tab if it does not load below.
